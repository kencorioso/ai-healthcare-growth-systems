# Dashboard

This directory documents the executive dashboard developed for the AI Healthcare Growth Systems project.

The dashboard will translate healthcare marketing and acquisition data into a concise view of business performance and areas requiring investigation.

## Planned Executive View

The dashboard may include:

- Marketing spend
- Leads
- Qualified leads
- Admissions or conversions
- Cost per lead (CPL)
- Cost per acquisition (CPA)
- Conversion rate
- Channel performance
- Performance trends over time
- Significant anomalies or changes
- AI-generated executive insights
- Recommended areas for human investigation

## Design Principle

**The dashboard should help an executive decide where to look next, not simply display more data.**

The goal is to reduce the distance between marketing data and executive understanding.

## Planned Tools

Potential tools include:

- Power BI
- Looker Studio
- Python-based visualization
- Other business intelligence tools as appropriate

The final dashboard platform will be selected as the project develops.
