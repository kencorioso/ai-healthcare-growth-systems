# Analysis

This directory contains the analytical work used to transform healthcare marketing data into actionable business insights.

The purpose of the analysis layer is to determine what the data actually shows before asking AI to interpret why a change may have occurred or what should be investigated next.

## Planned Analysis

The initial analysis will use Python and, where appropriate, SQL to evaluate:

- Marketing spend by channel and time period
- Lead and qualified-lead volume
- Admissions or conversions
- Cost per lead (CPL)
- Cost per acquisition (CPA)
- Conversion rates
- Channel efficiency
- Changes in performance over time
- Significant anomalies or performance shifts
- Relationships between marketing activity and business outcomes

## Analytical Principle

**Measure first. Interpret second.**

The analytical layer should establish observable facts from the data before those findings are passed to an AI model for interpretation.

AI may help identify patterns, generate hypotheses, and recommend areas for investigation, but conclusions should remain grounded in measurable data.

## Planned Tools

- Python
- pandas
- SQL
- Jupyter notebooks
- AI-assisted analysis

Additional tools may be introduced as the project develops.
