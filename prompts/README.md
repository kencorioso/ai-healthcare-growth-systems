# Prompts

This directory documents the AI prompts developed and tested as part of the AI Healthcare Growth Systems project.

The goal is not to create a single "perfect prompt." Instead, this directory will show how prompts evolve as the system is tested against different healthcare marketing scenarios and analytical problems.

## Prompt Development Principles

Prompts developed for this project should:

- Begin with the business question rather than the technology
- Require the AI to distinguish observations from hypotheses
- Ground conclusions in the available data
- Avoid inventing causes that cannot be supported by the data
- Identify areas requiring human investigation
- Communicate findings in language useful to healthcare marketing and executive leadership
- Support decision-making rather than attempt to replace human judgment

## Planned Prompt Categories

Initial prompts will include:

- Marketing performance analysis
- Attribution analysis
- Anomaly identification
- Executive summary generation
- Root-cause hypothesis generation
- Recommended next-step investigation
- Competitive and market analysis

Prompt versions and significant changes will be documented so the development process remains visible.
