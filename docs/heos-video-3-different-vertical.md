# HEOS Evidence Engine — Video 3: Different Healthcare Vertical

**Status:** Workstream E — Final / Freeze-Ready
**Tagline:** The Method Transfers. I Know How to Rebuild the System.
**Persona:** Hiring manager / executive in another healthcare vertical
**Core question:** If I hire Ken, can he build something like this around our organization?
**Target length:** approximately 90–110 seconds

## Full Script

I would not take the HEOS Evidence Engine built for Harbor Ridge, point it at your organization's data, and tell you it's portable. It isn't.

What is portable is my ability to build an evidence engine for a different area of healthcare, with the data model, operating relationships, terminology, and evaluation environment built around that organization.

If that organization were in orthopedics, for example, I wouldn't start with Harbor Ridge's schema. I'd start by understanding how that orthopedic business actually works, what systems hold the evidence, how a patient moves through the organization, where revenue is created or lost, and what questions leadership needs the data to answer.

And that's not a process I understand only in theory. I've already executed it end to end.

For Harbor Ridge, I mapped the source systems across eight operating categories. I built the relational data dictionary and database schema. I generated the synthetic operating data, designed hidden failure scenarios, froze the Ground Truth in advance, and then evaluated the AI under blind conditions.

That complete build process is part of the project record.

The specific model I would build for another organization would be different because the organization is different. But the discipline is repeatable: understand the business, map the systems, define the relationships, build the evidence architecture, and test the reasoning against answers established before the AI sees them.

The same principle extends beyond healthcare. A logistics company, for example, might connect lead source to quote, shipment, service performance, invoice, and collected revenue. That's an analogy, not a claim that Harbor Ridge has been validated in logistics.

So I'm not offering a universal healthcare schema or pretending I've built a plug-and-play product.

I'm showing you that I've already built this process once, from source-system mapping through blind evaluation, and I can build it again around the reality of your organization.

- This is a hiring pitch about demonstrated building capability, not a claim that the Harbor Ridge implementation itself is portable.
- Portability remains scoped to the method and process, not the Harbor Ridge schema, product implementation, or demonstrated cross-industry performance.
- The orthopedics example illustrates how the process would be rebuilt around a different healthcare organization; it is not a claim of prior orthopedics validation.
- The logistics example remains explicitly an analogy, not evidence of validation outside behavioral healthcare.
- The demonstrated process includes source-system mapping across eight operating categories, relational data dictionary development, schema design, synthetic data generation, hidden-scenario design, frozen Ground Truth, and blind evaluation.
- HEOS Evidence Engine remains the demonstrated V1 technology; Harbor Ridge Behavioral Health remains its synthetic evaluation testbed.
