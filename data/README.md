# Data

> **Status: HEOS V1 closed October 25, 2026.** The synthetic datasets are the CSV exports in `csv_export/` (baseline), `csv_export_scenario1/` and `csv_export_scenario2/`, generated by `generate_synthetic_data.py`. The sections below are the original plan.

This directory contains the synthetic datasets used to develop and test the AI Healthcare Growth Systems project.

No protected health information (PHI), patient-level information, or confidential employer or client data will be used in this project.

## Planned Dataset

The initial dataset will simulate healthcare marketing performance across acquisition channels and include metrics related to:

- Marketing spend
- Impressions
- Clicks
- Leads
- Qualified leads
- Admissions or conversions
- Cost per lead
- Cost per acquisition
- Conversion rate
- Marketing channel
- Time period

The dataset will be designed to support attribution analysis, anomaly detection, executive reporting, and AI-assisted investigation.
